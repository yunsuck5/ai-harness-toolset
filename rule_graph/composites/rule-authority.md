# 합성 — `rule-authority`

`rules/rule-authority.md`(쿡북)가 가리키는 합성 선언이다. **여기에만 권위가 있다.** 원소는 차단하지 못한다(불변식 4).

각 합성은 **어떤 key 들의 조합인지를 선언**하고, 참조 원소의 **내용 사본을 병기**한다. 사본은 배포 요건이다 — adopter 는 원소 트리를 받지 않는다. 정본은 각 key 가 소유한다(불변식 5).

`방향` 은 무엇을 막는지다. `정` = 작업을 막는다. `역` = **차단 주장 자체를 막는다.** `역` 은 설계에 없는 축이며 `_journal/FINDINGS.md` `F-3` 에서 도입됐다.

### RC-00026 — 권위 분류와 처분의 소유

- **authority**: true · **방향**: 정 · **조합**: `[RE-00045]` `[RE-00046]`

> 권위 분류와 처분의 정의는 규칙 `rule-authority` 가 소유한다. 다른 규칙 표면이 그 둘을 다시 정의하지 않는다.

**참조 원소 사본**

### RC-00031 — Hard gate 의 자격
